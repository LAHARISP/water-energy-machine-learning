| File                       | Responsibility                         |
| -------------------------- | -------------------------------------- |
| `generate_dataset.py`      | Generates our larger synthetic dataset |
| `resource_consumption.csv` | Stores historical consumption          |
| `data_loader.py`           | Loads and validates data               |
| `feature_engineering.py`   | Creates ML input features              |
| `model_training.py`        | Trains and compares ML algorithms      |
| `anomaly_detector.py`      | Detects unusual consumption            |
| `investigator.py`          | Suggests possible causes               |
| `visualizer.py`            | Generates ML prediction graphs         |
| `app.py`                   | Main application                       |
| `models/`                  | Stores trained ML models               |
| `reports/`                 | Stores reports and visualizations      |
